🎯 このアプリでできること
📍 基本の図形を描こう
点：クリックして点を打つ
線分：2点を結ぶ線
直線：どこまでも続く線
円：中心と半径で描く
三角形：3つの頂点を決める
四角形・多角形：好きな形を作る
🔧 便利な機能
ドラッグモード：点を動かして図形を変形できる！
軌跡モード：点を動かした道筋が見える
垂線：直角に交わる線を引く
平行線：平行な線を簡単に描ける
中点：線分の真ん中を見つける
二等分線：角度や線分を半分に分ける
🎬 アニメーション
図形が動いて、幾何学の変換が目で見てわかる！

回転：クルクル回る
拡大縮小：大きくなったり小さくなったり
平行移動：スーッと動く
反射：鏡に映ったように反転
変形：形が変わる様子を観察

🚀 使い方（初めての人向け）
ステップ1：図形を描いてみよう
点を打つ

上のツールバーで「📍 点」をクリック
キャンバス（白い画面）をクリックすると点が打てる
線を引く

「📏 直線」または「➖ 線分」をクリック
2回クリックすると線が引ける
円を描く

「⭕ 円」をクリック
1回目のクリックで中心を決める
2回目のクリックで大きさが決まる
三角形を描く

「🔺 三角形」をクリック
3回クリックすると三角形ができる
右側のパネルに辺の長さや角度が表示される！
ステップ2：図形を動かしてみよう
ドラッグモードをON

「🖐️ ドラッグ」ボタンをクリック
点の近くでマウスを押したまま動かすと、点が動く
図形が変形する様子を観察しよう！
軌跡を記録

「📈 軌跡」ボタンをクリック
ドラッグモードで点を動かすと、通った道が赤い線で残る
どんな形になるか実験してみよう
ステップ3：アニメーションを見よう
図形を描く（三角形や円など）
「▶️ アニメーション」ボタンをクリック
好きなアニメーション（回転、拡大縮小など）を選ぶ
「▶️ 再生」で動き出す！
ステップ4：定理を学ぼう
三角形を描く
「📚 証明」ボタンをクリック
「三角形の内角の和」を選ぶ
「次のステップ ▶️」で証明を1つずつ見ていく
ステップ5：保存と共有
「💾 保存」ボタンをクリック
画像として保存：PNG形式でダウンロード
データを保存：あとで続きができる
共有URL：友だちに見せるリンクを作成

🎨 使い方のコツ
💡 ヒント1：正確な図形を描くには
グリッド（マス目）を目安にすると、きれいに描ける
中心軸（縦横の太い線）を使うと対称な図形が作りやすい
💡 ヒント2：複雑な図形を作るには
まず基本の図形（三角形、円など）を描く
中点や二等分線を使って補助線を引く
ドラッグモードで調整する
💡 ヒント3：実験してみよう
三角形の1つの点を動かすと、角度や面積がどう変わる？
円の中に三角形を描いて、頂点を円周上で動かすと？
軌跡モードで点を円の周りに動かすと、どんな形になる？
💡 ヒント4：友だちと共有
作った図形を「共有URL」で送ると、同じ図形を見られる
「これはどんな図形？」とクイズを出し合おう
